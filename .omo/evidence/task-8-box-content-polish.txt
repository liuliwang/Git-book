## 关键发现：shellinbox 样式定义损坏（本次修复）

原定义（第 89 行）嵌套 `\lstset{style=shell, ...}` 且含空值键 `backgroundcolor={}` / `rulecolor=`，
导致所有 10 处 `\begin{lstlisting}[style=shellinbox]` 触发 keyval 解析错误：

- `! Missing \endcsname inserted.` / `! Extra \endcsname.`
- `! Package keyval Error: No value specified for framesep.`
- 涉及行：637 / 1023 / 1031 / 1039 / 1055 / 1416 / 2618 / 2635 / 2650 / 2666

根因：`\lstdefinestyle` 样式体内再嵌套 `\lstset{...}` 时，listings 会把 `\lstset` 内部的
`\begingroup` 泄漏到 keyval 键名解析（`\KV@split ... \begingroup`），且空值键无法被 keyval 消费。
最小实验（lsttest.tex）验证：嵌套 lstset 写法必报错，完整显式键列表写法通过。

修复（第 89 行）：
```
\lstdefinestyle{shellinbox}{basicstyle=\ttfamily\small, frame=none, breaklines=true,
  columns=flexible, keepspaces=true, showstringspaces=false,
  moredelim=[il][\color{gray}]{\#},
  xleftmargin=0pt, xrightmargin=0pt, aboveskip=0pt, belowskip=0pt, framesep=0pt}
```
- 不再嵌套 `\lstset`，完整列出所需键（复制自 shell，去 backgroundcolor/rulecolor 键）
- frame=none + 无 backgroundcolor ⇒ 无边框、无灰底，tcolorbox colback 透出
